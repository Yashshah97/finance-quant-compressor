# Usage

```python
import finance_quant_compressor
```

Each module is self-contained; see docstrings for the API:

- `finance_quant_compressor.encoder` — Domain-tuned encoder implementation
- `finance_quant_compressor.benchmarks` — Ratio benchmarks and comparison functions
- `finance_quant_compressor.metrics` — Risk metric calculations and aggregation
- `finance_quant_compressor.utils` — Utility functions for data processing and compression
- `finance_quant_compressor.tests_test_encoder` — Unit tests for the encoder implementation
- `finance_quant_compressor.core` — main domain logic and public entry points
